Backend local del equipo

Requisitos: Node.js 22 o superior, Docker con Compose activo.
Desde la raíz del repositorio ejecutar:

  npm ci
  npm start

El comando levanta PostgreSQL y backend, aplica migraciones y prepara cuentas
de demostración y un platillo sin borrar cuentas ni datos anteriores.
No requiere .env.project.credentials ni recibir contraseñas de otra persona.
El backend queda en http://127.0.0.1:3000/api (puerto configurable).
Los accesos propios de esta computadora están en accesos-demo-local.txt.

En Postman importar:
  postman/Local-Demo.postman_collection.json
  postman/.env.demo.local
Seleccionar el environment Demostración local y ejecutar la colección en orden.
Crea un pedido, pago simulado, entrega y reseña; luego consulta los reportes.
Cada ejecución conserva esos datos de demostración.
Los archivos que empiezan con punto pueden estar ocultos: Ctrl+H para verlos.

Para detener sin borrar datos: npm stop
Para ver registros: npm run logs
Conservar .env.compose.local: contiene la configuración privada del volumen y
la semilla de las cuentas demo. No subirlo ni subir accesos-demo-local.txt
o postman/.env.demo.local al repositorio.
Las historias deben estar integradas en la rama descargada para poder probarlas.
