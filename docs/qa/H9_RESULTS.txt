H9 (#40) - Recogida y confirmación de entrega

Prisma generado y backend compilado. Migración aditiva aplicada en PostgreSQL local.
H6/H7/H8/H9: 62 pruebas aprobadas. Unitarias: 25. Integración HTTP: 109 comprobaciones.
H9 en Docker: 10 pruebas aprobadas (9 casos y suite padre).
Incluye flujo H7 toma, H8 platillos listos, H9 recogida/entrega mediante HTTP.
Se comprueban actores/fechas UTC, transiciones, concurrencia, permisos, errores y notificaciones.
Las pruebas verifican que comanda y cuenta permanecen intactas al recoger y entregar.
Los errores de notificación mostrados son fallos intencionales para comprobar persistencia.

Reproducir desde la raíz con Docker activo:
 npm ci
 npm start
 npm run prisma:generate --workspace backend
 npm run build --workspace backend
 H9_API_URL=http://127.0.0.1:3000/api node backend/scripts/run-qa.cjs node --test backend/test/h9-integration.test.cjs
El ejecutor QA requiere PostgreSQL local con nombre terminado en _test.
Los fixtures son temporales en esa base; la limpieza se limita a los creados por la ejecución.

Postman: importar H9-Order-Delivery.postman_collection.json y H9-Local.postman_environment.json.
Seleccionar environment y completar cuenta WAITER, branchId y orderId de un pedido READY propio de prueba.
Ejecutar pasos en orden: rechazar entrega directa, recoger, rechazar duplicado, entregar, rechazar duplicado.
