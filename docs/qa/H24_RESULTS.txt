H24 (#55) - Promedio de calificaciones por sucursal
Fecha: 2026-11-14 (America/El_Salvador)

Implementación: GET /api/management/branches/:branchId/ratings/summary
Roles MANAGER de su sucursal y GENERAL_MANAGER. Otra sucursal para MANAGER: 404.
Agregación Prisma en una consulta sobre Review: suma y conteo, redondeo a un decimal.
Sin reseñas: promedio null y conteo 0. No se persiste el promedio ni se cambia el esquema.
Filtro opcional dateFrom/dateTo YYYY-MM-DD; ambos requeridos cuando se filtra.
Reutiliza validación de fechas local del backend (desde el año 2000).
Intervalo local UTC-06:00 desde inicio de dateFrom hasta inicio del día posterior a dateTo, exclusivo.

Build aprobado. H23 + H24: 33 pruebas aprobadas. Unitarias backend: 25 aprobadas.
Pruebas: sesión, roles, sucursal inexistente/ajena, gerente sin sucursal, fechas inválidas,
límites locales exactos, aislamiento de sucursales, redondeo y resultados vacíos.
Una reseña registrada por la API H23 aparece inmediatamente en H24.
Las consultas no modifican reseñas; los fixtures temporales se eliminan al terminar.

Reproducir desde la raíz con Docker activo:
 npm ci
 npm start
 npm run prisma:generate --workspace backend
 npm run build --workspace backend
 H24_API_URL=http://127.0.0.1:3000/api node backend/scripts/run-qa.cjs npm run test:h24 --workspace backend
El ejecutor QA exige PostgreSQL local con nombre terminado en _test.

Postman: importar H24-Ratings-Summary.postman_collection.json y H24-Local.postman_environment.json.
Completar credenciales existentes, sucursal del gerente y otra sucursal; seleccionar environment.
15 solicitudes con JSON y scripts validados; no ejecutadas en Postman/Newman.
