H25 (#56) - Consulta de reseñas por sucursal
Fecha: 2026-11-14 (America/El_Salvador)

GET /api/branches/:branchId/reviews?rating=1..5&page=1
Roles: CUSTOMER y GENERAL_MANAGER cualquier sucursal existente; WAITER/MANAGER solo su sucursal.
KITCHEN devuelve 403. Sucursal inexistente o fuera de alcance del personal devuelve 404.
Página fija de 10, orden createdAt DESC e id ASC.
Solo se seleccionan id, rating, comment y createdAt; no se incluyen datos del perfil ni IDs de autor/pedido.
Conteo y página se leen en transacción RepeatableRead para conservar una vista consistente.
Sin nuevas tablas ni migraciones; no se implementan edición ni eliminación.

Build aprobado. H23/H24/H25: 44 pruebas aprobadas.
Pruebas: permisos, sesión, filtros inválidos, paginación sin duplicados, orden estable,
ausencia de datos privados de perfil, inserción concurrente entre conteo y lectura,
reseña nueva por API H23 y rechazo de rutas de modificación.
Los fixtures temporales se limpian sin eliminar datos previos del equipo.

Reproducir desde raíz con Docker activo:
 npm ci
 npm start
 npm run prisma:generate --workspace backend
 npm run build --workspace backend
 H25_API_URL=http://127.0.0.1:3000/api node backend/scripts/run-qa.cjs npm run test:h25 --workspace backend
El ejecutor QA exige PostgreSQL local con nombre terminado en _test.
